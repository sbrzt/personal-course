# About

This course was written for Sebastian Barzaghi (University of Bologna) as part of a personal curriculum on AI for research in the digital humanities. It is public so that others can use it, and so that the work in it is open.

## How it was made

The curriculum, the lessons, the `course` package and the checks were drafted with Claude (Anthropic), working from the author's PhD project and data, and are reviewed and revised by the author. Every lesson is executed automatically before publication: each solution must pass its checks, and each blank exercise must run cleanly. Mistakes remain possible; please report them as issues on GitHub.
